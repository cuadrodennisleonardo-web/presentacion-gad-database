# Project Rules & AI Agent Instructions

## UI & Design Guidelines
- **STRICT NO EMOJI RULE**: Do NOT use raw emoji icons (e.g., 🎓, 🏥, 🤝, 🏘️, 🏫, 🏗️, 🗺️, 📅, ⚡) anywhere in UI components, dropdown options, subsector labels, badges, buttons, headers, or code labels. Use clean text or official SVG icons (e.g. Lucide icons) instead.
